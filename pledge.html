Pledge

Hold me to it.

I use everything I build. That's the whole pledge, really.

It breaks for me first, so bugs, security holes, and whatever the next dependency update ruins all get fixed. I won't promise speed (there's one of me) but I'll promise attention. Nothing gets ignored, or closed as stale. Most of what I make will stay free. If something ever does go paid, you're paying me to run it profitably, not to unlock it: every feature will exist in the version you can host yourself, and you can walk out any time with your data in your hands. What's open stays open. Period. I'm not going to relicense something you already built on. And if a project ever has to end, that's the last resort, never the plan: you'll get fair warning, a final release that works, and the repo left up so someone else can take it from here.

If I ever break this, tell me:
